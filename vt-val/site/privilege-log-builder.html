Privilege log builder

Document set in (author, recipients, date, type, subject) → draft privilege log entries with FRE 26(b)(5)-style fields. Privilege types are inferred from metadata heuristics (attorney-client patterns, work-product document types), near-duplicates grouped, incomplete entries flagged — every inference tagged metadata_heuristic for attorney review. Exports a court-ready Markdown log and CSV.
