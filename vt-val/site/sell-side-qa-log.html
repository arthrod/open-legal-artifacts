Sell-side Q&A log

A diligence Q&A log whose core cross-examines the answers: questions carry buyer, category, and answer history (draft/sent); deterministic heuristics detect contradictions between answers — numbers by canonical unit and magnitude, terms by antonym pairs — each flagged with verbatim evidence quotes; sent answers carry data-room citations; an approve→send release gate is code, not convention; and a disclosure-readiness score is computed from the log itself. Open reimplementation of Anthropic's closed artifact.

Worked example (fictional): Project Copperfield, three buyers, eight questions — including a pending draft that quietly changes the EBITDA story.

Bring your own log

Import a buyer-questions .docx — the extracted questions land in an editable preview; Apply loads them into the log box below. Imported questions start open: no answers, no auto-drafting. Or paste a log JSON directly ({ items: [{ id, buyerId, category, question, receivedAt }] }). The board, contradictions, gate and readiness score recompute from whatever log is loaded.
