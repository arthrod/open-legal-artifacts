Tabular review

A documents × questions matrix where the core verifies, never answers: a cell counts as answered ONLY when its answer carries a quote that actually locates in the document (exact or normalized; fuzzy anchors but is flagged) and, on typed questions, satisfies the machine-checked schema. Everything else is UNVERIFIED with a reason — never guessed. Click a cell to inspect it, correct an extraction, and mark decisions; every citation opens the source at the exact passage.

Worked example (fictional): 13 agreements × 5 questions — 66 cells, including one deliberately unanswered, one quote that does not locate, one typo'd (fuzzy) quote, a liability clause that is genuinely absent, one unclear notice clause, and one extraction that references an unknown document.

Controls

Summary

Matrix

Review matrix. Activate a cell answer to open its detail panel; activate a citation button to open the source document at the passage.

Re-run & diff

Re-runs the deterministic core on the current working input and diffs it against the saved snapshot (diffMatrices — added / removed / changed cells). Extraction edits and corrected re-extractions show up here.

Bring your own document

Paste a contract and add it to the review set. Its cells start UNVERIFIED — no answer supplied — the core never answers; open a cell and supply an answer + quote to watch it verify.

Advanced — raw JSON input (documents / questions / cells)
