Playbook from agreement

Paste an agreement → clause splitter → match each clause against a bundled ACC-style playbook (preferred / ordered fallbacks / avoid, with rationale) → verify every position's source quote against the pasted text (exact / normalized / fuzzy / not_found) → deviation table, RYG risk summary, and an exportable Markdown playbook draft. Clauses no rule covers stay uncovered — never guessed. deterministic simulation of the live app — no LLM, no network; all data fictional.
